2.10.8 notes

What changed,
and what did not.

A readable ledger. Every item is implemented in the source or measured on the release build; the unverified items are labelled.

Smaller binary

  • The self-destruct waiter now launches through the existing hidden ShellExecuteW path instead of linking std's process spawner.
  • The portable exe is 542,720 bytes, 55,808 bytes smaller than 2.10.7 and 54,272 bytes below 596,992.
  • Bundled rust-lld with ICF supplies the final link while opt-level 3, fat LTO, one codegen unit, panic-abort, and stripped symbols stay in place.
  • Event-gated sprint and crosshair reads from 2.10.7 are unchanged; polling cadence and bindings are unchanged.
  • An isolated 60 s sample measured 2.10.7 at 31.25 ms idle / 125 ms armed CPU and 9/s / 126/s sprint-thread context switches. The 2.10.8 build stayed in the same low CPU range; these are short samples, not a speedup claim.
  • Tests are 26 / 26. No CPU, end-to-end latency, zero-latency, or render-speed claim is made.

Still included

  • Process-verified Java/Bedrock detection from 2.10.1, with browser, chat, editor, and launcher rejection.
  • Hydrogen's literal A6 Anchor order, 47/53 ms defaults, fixed 37–43 ms early settles, and the Air loop.
  • The 8 px logical radius across paint, fallback region, DWM, and capture mask.
  • Other modules keep their configured delays. The game tick and Windows scheduling remain.
  • Self-destruct still holds for one second, purges Droplet's data, and recycles the portable executable.
  • Dash, Shield, and Pearl still select and click in one SendInput batch.

Not added

  • No streamproof or capture-evasion mode.
  • No anti-cheat bypass, process hiding, log erasure, or input disguise.
  • Detection asks Windows for the owning process image; it does not read game memory.
  • No unrestricted or “100% no restriction” mode and no instant-speed claim. Anchor keeps its fixed early settles and a configured final settle; the game loop remains.
  • No MSIX/AppX, installer, or ZIP. The exe is the only Windows artifact.
  • No zero-latency claim and no silent auto-updater.
  • No Linux or macOS package until the platform layer exists.

Ledger

Release
history.

The versioned notes in the repository are the source of truth. This page is a readable mirror, not an automatically generated feed.

2.10.8

Smaller portable exe

Hidden ShellExecuteW replaces the only std::process::Command use, and rust-lld + ICF cuts the binary to 542,720 bytes. Event-gated reads are unchanged.

2.10.7

Event-gated reads

Sprint settings are read only when a pulse is due, and crosshair settings only on a magenta hit; polling and bindings are unchanged.

2.10.6

Idle sprint poll

The sprint watcher parks at 100 ms while inactive and wakes immediately on focus or settings changes; the armed 8 ms cadence is unchanged.

2.10.5

Idle watcher gates

The sprint and crosshair watchers skip the settings lock while inactive; cadence and visuals are unchanged.

2.10.4

Transparent mark, leaner loop

The favicon tile and brand plate are gone, and the focus-only presence loop no longer takes the settings lock every 160 ms.

2.10.3

Click-through corners, lighter watcher

Transparent rounded corners pass clicks through, and the watcher reuses a verified foreground game window instead of re-resolving it every 160 ms.

2.10.2

Clean corners, matched mark

DWM-first antialiased 8 px corners with a hard-region fallback, and a favicon/header mark that matches the app's outlined droplet.

2.10.1

Process-verified game detection

Browsers, Discord, editors, and the launcher no longer trigger Game detected; two samples confirm a real Java or Bedrock process.

2.10.0

Hydrogen Anchor, tighter corner

Literal A6 Anchor order, 47/53 ms defaults with Air loop, one 8 px radius across paint and capture, and a local vault-graph site.

2.9.3

Reliable Anchor, exe only

Anchor 55/65 ms safe settle, top accent strip and outer rim removed, and MSIX/AppX/ZIP packaging retired for one direct 591,872-byte exe.

2.9.2

Independent sliders, knob switches

Min/Max no longer rewrite each other, the 28×16 knob switch returns, Anchor 37–97 / 43–103 with 37/43 defaults, outer rim removed, Self-destruct restored. Last release with ZIP/MSIX artifacts.

2.9.1

Borderless cards, text controls

Module glyphs removed, text ON/OFF pills, borderless cards, Anchor tick-floor row retired, 592,384-byte exe and 301,774-byte MSIX.

2.9.0

Power controls and downloads

Round power buttons, transparent item glyphs, compact Dash, sticky hide, 1 s self-destruct, same-frame Dash/Shield/Pearl input, Windows ZIP and MSIX, GitHub release workflow.

2.8.0

Fitted corners and lighter paint

One 13 px radius across paint, window region, and capture mask; allocation-free binding chips; 594,944-byte binary; editorial site rebuild.

2.7.0

Accent and per-module modes

RGB presets and channel sliders, Hold/Toggle chips on every trigger card, and tighter fast-module defaults.

2.6.2

Rounded window, single mark

Window corners follow the painted radius; the brand mark becomes one transparent droplet.
