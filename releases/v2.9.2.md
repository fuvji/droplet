# Droplet 2.9.2 — Independent sliders, knob switches, clean edges

Released 2026-11-11.

Droplet 2.9.2 is a UI and timing correction release. It fixes the coupled
Min/Max sliders, restores the original sliding knob switch, widens the Anchor
timing domains, removes redundant Anchor sleeps, restores the explicit
Self-destruct label, and deletes the painted outer rim. It does not add an
unrestricted-speed mode or make a zero-latency claim.

## GUI

- Every module now uses the original 28×16 sliding switch: a plain track and a
  5 px-radius knob. There is no ON/OFF text, no power glyph, and no outline.
- The two Min/Max sliders are independent. Dragging one clamps only that field;
  the partner value is not lifted or rewritten. `smart::pick` sorts a
  temporarily inverted pair at execution time.
- Anchor exposes Min **37–97 ms** and Max **43–103 ms**. New and migrated
  defaults are **37 / 43**.
- The painted outer hairline is gone. DWM's border was already suppressed, so
  the panel no longer has a second rim at the rounded corners.
- The Danger zone action is labelled **Self-destruct** again. It keeps the
  one-second hold, progress indication, data purge, and portable-executable
  recycle.
- Cards remain one borderless surface. The navigation rail keeps its small
  original line icons.

## Timing and input

- The Anchor 50 ms tick floor and the three hardcoded 50 ms `tap_slot` sleeps
  were removed.
- Each Anchor slot now gets exactly one configured wait before its right-click;
  the old second wait after every action was also removed. At the defaults,
  the sequence has three 37–43 ms settles instead of three 50 ms fixed sleeps
  plus two 50–103 ms waits.
- Other modules keep their existing configured delays. There is no mode that
  removes the Minecraft tick, Windows scheduling, or the configured sliders.
- The focus gate, master gate, per-module busy guards, and distinct-slot checks
  are unchanged.

## Performance

- Trigger routing is unchanged: **0.45 ns** indexed versus **202.39 ns**
  scanned (445×, routing only).
- Removing the three fixed Anchor sleeps and two post-action waits is a real
  reduction in the sequence's own delay. It has not been validated against a
  live Minecraft client.
- The System-tab paint snapshot in the 2.9.2 capture read **2.15 ms**. This is
  one sample, not a frame-time benchmark, and no render-speed claim is made.

## Known limits

- No live Minecraft client is available in this workspace, so hit registration,
  the 37–43 ms Anchor settle, and same-frame input ordering are unverified in
  game.
- No unlimited or “100% no restriction” mode. The game tick and Windows
  scheduling remain real boundaries; redundant app-side waits were removed,
  not the game loop.
- Windows is the only supported platform. Linux and macOS packages are not
  produced because the core has not been ported.
- The portable exe is unsigned. The MSIX uses a development certificate.
- No auto-updater. Silent self-updating would require network access and a
  signed update channel, contradicting the current no-network design.
