# Droplet 2.10.11

Released 2026-11-15. This is the final handoff build: formatting cleanup,
load-time duplicate-binding normalization, and deterministic image generation.
It makes no CPU, latency, render-speed, or size claim.

## Highlights

- **Formatting is clean.** The complete source tree now passes
  `cargo fmt --check`. This is a source-formatting change only; routing,
  timings, input hooks, and the release profile are unchanged.
- **Legacy duplicate chips are cleaned on load.** A hand-edited or old config
  can contain the same input on two trigger chips. `normalize()` now clears the
  earlier owner using the same last-wins order as the runtime trigger index, so
  the painted chips and the hook agree. Anchor's `XButton1` assignment no longer
  leaves a misleading duplicate on Breach; a short-press or toggle-off restore
  is unaffected.
- **Captures are deterministic.** `tools/capture-tabs.ps1` now starts Droplet
  with an isolated temporary `LOCALAPPDATA` and a seeded config. Published
  images cannot inherit a developer's personal toggles or duplicate bindings.
  The four 624×408 images are regenerated from this build with Anchor shown on
  `XButton1`.
- **Release metadata is synchronized.** README, changelog, benchmark notes,
  vault notes, download README, checksums, workflow hash, product page, release
  ledger, and the release note all describe 2.10.11.

## Boundaries

Droplet remains local and visible. It has no game-memory access, network calls,
telemetry, streamproof/capture-evasion mode, anti-cheat bypass, input disguise,
or silent auto-updater. The portable exe is unsigned, so SmartScreen may warn.
Live Minecraft injection and hit registration remain unverified here.
