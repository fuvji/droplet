# Droplet 2.10.13

Released 2026-11-16. This is a same-day visual hotfix for 2.10.12. The
authoritative GDI region fixed the Windows 10 corner clip, but DWM continued
to paint its own light square non-client frame around that region. That left a
one-pixel square outline in the four corners, which looked like a broken or
painted-on radius.

## Highlights

- **The square DWM frame is gone.** The region path now explicitly tells DWM
  not to round the window and clears the border color before returning. DWM no
  longer draws a competing square edge around the GDI silhouette. Non-client
  rendering is deliberately left enabled: disabling it also disables the
  acrylic composition and makes desktop text visible through the panel.
- **The rounded region remains authoritative.** The 8 px GDI region is still
  installed first and replaced on DPI changes. DWM is only a fallback if the
  region API fails, in which case DWM is allowed to round the window.
- **The published captures no longer use a hardcoded decorative mask.** The
  capture helper reads the live window's region with `GetWindowRgn` and applies
  that exact alpha mask. A screenshot can no longer hide a square frame behind
  a hand-drawn rounded path.
- **The timer and sleep work from 2.10.12 is retained.** The timer must be
  requested from the kernel's finest value (`max`), held at 5,000 × 100 ns
  where supported, and reasserted while low latency is enabled. The
  system-required execution state remains tied to the same toggle.

## Verification

- A live-window capture with a magenta backdrop shows a rounded silhouette and
  no square light frame. The actual window region remains 624×408, with the
  corner point outside and the center inside.
- The System panel and an independent kernel query both reported **0.5 ms**
  while low latency was enabled on this host.
- `cargo test --release --locked --target x86_64-pc-windows-gnu`: 39 passed.
- `tools/check-release.ps1`: 67 checks passed.
- `powercfg /requests` requires administrator elevation and was not run, so the
  anti-sleep request is implemented and compiled but not independently
  observed here.
- No separate Windows 10 machine or live Minecraft client was available. Live
  injection, hit registration, and per-device timer floors remain unverified.

## Boundaries

Droplet remains local and visible. It has no game-memory access, network calls,
telemetry, streamproof/capture-evasion mode, anti-cheat bypass, input disguise,
or silent auto-updater. The portable exe is unsigned, so SmartScreen may warn.
