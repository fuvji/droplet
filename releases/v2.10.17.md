# Droplet 2.10.17

Droplet 2.10.17 is the translucent-glass release. It replaces the near-black
panel with an acrylic-style gray aurora, makes the layered surface genuinely
see-through, removes the last bold and squared-off details, and keeps the
624×408 layout and every local-only boundary.

## Material

- The panel now composites at **84% opacity** (`PANEL_ALPHA = 214`). Because the
  alpha lives in the layered surface itself, the desktop shows through the
  glass; the corners stay antialiased.
- DWM system-backdrop and accent-policy requests were removed. On this layered
  window they made the compositor paint an opaque layer behind the surface,
  which cancelled the translucency. A live screen capture over a magenta test
  backdrop confirmed the change: the backdrop is now visible through the panel.
- The background is a smooth graphite wash with three very low-alpha aurora
  blooms (slate teal, cool indigo, muted mauve) and a faint top light. The rail
  is a second pane of glass rather than an opaque strip.
- The aurora is composed once per surface size into a cached buffer and copied
  into the DIB before each repaint. Card fills stay opaque in the GDI+ pass —
  blending large translucent rectangles was the expensive part of the frame —
  while the whole panel still carries the translucent alpha.

## Type and shape

- **`LOCAL / WINDOWS` is gone.** The header now carries one light title,
  optically centred, with quiet space around it.
- **Thin type throughout:** Segoe UI Light (Segoe UI fallback), no bold
  anywhere. The title is 16 px, card titles 12 px, rows 9.5 px, and the dim
  labels were lifted so thin stems stay readable on gray glass.
- **Softer, cleaner corners:** the window radius is 18 px (was 12) and cards
  use 15 px. Every corner is a real curve; there are no square tiles and no
  thick tonal wedge at the panel edge.
- Rows are 22 px with a 23 px title band, so the cards breathe without moving
  the 624×408 layout. Sliders are thinner (2.5 px track, 3.6 px thumb), icon
  strokes scale with DPI, and hairline separators replace heavier rules.

## Performance

The first implementation stacked GDI+ bloom ellipses and measured **81.45 ms**
in the System render readout. It was replaced with the cached pixel backdrop:
the same readout now measures **5.32 ms** for a full repaint on this machine.
That is a fix for a measured regression in the new material, not an
end-to-end speedup claim against 2.10.16.

## Limits

- The DPI captures exercise the application's `WM_DPICHANGED` path on a 96 DPI
  host; they are not a physical 125% or 150% monitor test.
- The desktop shows through the glass without a compositor blur. DWM acrylic
  is not used because it made this layered window opaque, so there is no
  blurred backdrop copy and no screenshot or capture API involved.
- No live Minecraft client is available here, so in-game hit registration
  remains unverified.
- The input harness still cannot reliably record synthetic Shield output on
  this desktop; that check remains unresolved, not a pass.
