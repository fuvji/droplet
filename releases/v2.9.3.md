# Droplet 2.9.3 — Reliable Anchor, single exe, clean top edge

Released 2026-11-11.

Droplet 2.9.3 fixes Anchor placement by restoring a tick-safe settle, removes
the last bright edge from the panel, and retires MSIX/AppX and ZIP packaging.
The Windows release is now one direct executable.

## Anchor fix

- The 37–43 ms settle could complete inside one 50 ms Minecraft tick. The slot
  change and right-click then used the previously selected item, so the block
  was never placed.
- Defaults are now **55 / 65 ms**, with Min **55–97 ms** and Max **65–103 ms**.
  The 55 ms floor crosses a client tick before the right-click.
- The sequence still uses exactly one settle per slot and no duplicate
  post-action wait. The focus gate, busy guard, and distinct-slot check remain.
- This is not validated against a live Minecraft client in this workspace.

## GUI

- The 1 px accent strip at the top of the window is removed.
- The painted outer hairline remains removed. DWM's rounded clip and the
  edge-to-edge graphite surface are the only boundary.
- The 28×16 sliding knob switch, independent Min/Max fields, borderless cards,
  and the Self-destruct label remain.
- The panel is still 624×408 logical pixels.

## Packaging

- MSIX/AppX, the installer, the development certificate, ZIP packaging, and the
  package scripts are removed.
- The site and tag workflow publish only `droplet.exe` and `SHA256SUMS.txt`.
- The installed 2.9.2 AppX package was removed from the build machine.
- There is no package registration to slow first launch; the exe is native and
  has no runtime dependencies. No “instant” or zero-latency guarantee is made.

## Verification
