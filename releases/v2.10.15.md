# Droplet 2.10.15

Droplet 2.10.15 is the corner-cleanup release. It replaces the hard GDI window
region with a layered alpha surface and fixes the geometry defect that left a
one-pixel spike at every right and bottom corner of the interim build.

## Fixed

- **All four corner arcs now have the same geometry.** The preview build placed
  the right and bottom circle centres on the window edge instead of one radius
  inside it, so those arcs were effectively quarter-circles centred outside the
  panel. The mask now mirrors each pixel into one local corner box; the circle
  centre is always `(radius, radius)` inside that box. The result is a
  symmetric silhouette with no protruding pixel at the right or bottom edge.
- **The 12 px radius is consistent.** Paint, the layered alpha mask, the
  transparent-corner hit test, DPI resizing, and the capture helper all use the
  same logical radius. The previous 8 px window edge did not match the 12 px
  card language.
- **4×4 coverage sampling.** Each corner pixel is sampled sixteen times instead
  of once. The resulting alpha ramp has seventeen levels across the rim, which
  removes the coarse single-sample staircase while preserving the crisp,
  borderless edge.
- **One-buffer compositing pass.** The old path wrote the full-buffer alpha,
  premultiplied the full buffer again, and rewrote the corner blocks. It now
  computes coverage, applies alpha, and premultiplies in one pass. No speedup is
  claimed without a separate benchmark.
- **Reset restores the shipped defaults.** Reset now restores **Keep panel open**
  to on. It was already the default, but the reset handler previously copied the
  old value forward and could leave the panel able to disappear on the next
  focus tick.
- **Captures use the same silhouette.** The capture helper applies the mirrored,
  supersampled mask when the layered window has no GDI region. All four
  624×408 site captures were regenerated from the tagged build.

## Kept

- The local, 32 KiB-capped `%LOCALAPPDATA%\Droplet\dwm.log` records DWM
  attribute HRESULTs, the region clear, size, and DPI. It never transmits.
- The Windows 10-safe layered silhouette does not depend on DWM's Windows
  11-only corner preference.
- The 2.10.12 held 0.5 ms timer, anti-sleep state, DPI-correct hit testing,
  pre-indexed trigger routing, and event-driven paint path are unchanged.
- No network, telemetry, game-memory access, capture evasion, anti-cheat
  bypass, input disguise, or privilege escalation was added.

## Limits

The live window was captured over a magenta backdrop on this Windows 11 host,
and the four 624×408 GUI captures were regenerated. No physical Windows 10
machine or live Minecraft client is available here, so Windows 10 compositor
behavior and in-game hit registration remain unverified. The input harness
still cannot reliably record synthetic Shield output on this desktop; that
official check is reported as unresolved, not as a pass. No CPU, latency, or
render-speed win is claimed.
