# Droplet 2.9.1 — Borderless cards, text ON/OFF controls

Released 2026-11-11.

Droplet 2.9.1 is a small debloat and cleanup release. It removes the module
glyphs and the per-card outlines, restores a compact text ON/OFF control, and
makes the shipped binary smaller. The input engine, trigger routing, and
product boundaries are unchanged.

## GUI

- Every module glyph is gone. Cards no longer carry a chip, a plate, or an
  icon of any kind.
- The round power glyph is replaced by a compact text **ON/OFF** pill. The
  pill keeps distinct on, off, and hover states without a border.
- Module cards are now one borderless surface. The per-card hairline outline
  was removed, and the single outer window hairline is thinner (0.75 logical
  pixels instead of 1.0).
- The Anchor card lost its `Tick floor` row and is one row shorter. The macro
  still applies the 50 ms Minecraft tick floor before the next hotbar action;
  the row was only a repeated label.
- The navigation rail keeps its four small line icons, so the tabs remain
  readable without any module artwork.

## Size and code

- Portable executable: **592,384 bytes**, down from 601,600 bytes in 2.9.0
  (9,216 bytes, about 1.5% smaller).
- Signed MSIX: **301,774 bytes**, down from 306,082 bytes.
- Deleted the item-glyph painter (about 200 lines), the two-letter card-code
  helper, the diamond path helper, the per-card outline draw, and the unused
  switch-luminance field.
- Removed `site/public/assets/module-icons.svg` and the 15 inline module icon
  references, so the site serves one fewer request and less HTML/CSS.

## Performance

- No routing change. The trigger-routing benchmark remains 0.45 ns indexed
  versus 202.39 ns scanned (445×, routing only).
- The app's own System-tab paint snapshot read **2.86 ms** after this change
  versus **2.60 ms** before it. That is a single snapshot, not a benchmark, and
  this release does **not** claim a render-speed win. The measured win here is
  binary size and removed code, not frame time.

## Known limits

- No live Minecraft client is available in this workspace, so hit
  registration and same-frame input ordering are unverified in game.
- Windows is the only supported platform. Linux `.deb`/AppImage/`.tar.gz` and
  macOS `.dmg`/`.zip`/`.img` packages are not produced because the core has
  not been ported.
- The portable exe is unsigned. The MSIX uses a development certificate.
- No auto-updater. Silent self-updating would require network access and a
  signed update channel, contradicting the current no-network design.
