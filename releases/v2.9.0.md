# Droplet 2.9.0 — Power controls, transparent item glyphs, downloads

Released 2026-11-11.

Droplet 2.9.0 is a focused GUI and distribution release. The input engine is
still local, visible, and tick-aware. This release does not add capture
evasion, anti-cheat bypass, input disguise, or a zero-latency claim.

## GUI

- Module toggles are now round power buttons with an open-top power glyph.
  On, off, and hover states are distinct without adding a background plate.
- Every module card uses an original 18 px item-style line glyph: pearl,
  shield, spear, mace, potion, crystal, anchor, totem, grass block, sword,
  player head, repeater, and chest. They are drawn from GDI+ primitives, use
  no Mojang textures, and have no chip or square background.
- The Dash card lost its redundant “Clicks 1x” row and is one row shorter.
- The Behaviour card no longer carries the Capture row. The public audit and
  documentation still state the factual capture status: ordinary visible
  composition, no streamproof mode.
- Anchor now exposes a 37–43 ms Min/Max window and ships at 37/43. The macro
  still applies the 50 ms Minecraft tick floor before the next hotbar action,
  and the card states that floor explicitly.
- The System palette is a deeper graphite with warm white text, a single
  accent hairline at the top edge, and the same 13 px corner radius.
- The tray icon and its menu were removed. Hiding the panel is sticky: an
  alt-tab or focus change can no longer resurrect it. Use Ctrl+Right Shift to
  show it again.
- Close now stops the watchers and exits immediately after the final save.
- The self-destruct hold is one second, with a visible progress percentage.

## Input

- Dash, Shield, and Pearl now select the slot and click in one `SendInput`
  batch, so the client receives the selection and the use action in the same
  input frame. Ordinary input only; the focus gate and game tick still apply.
- The low-level hooks now check the prebuilt trigger table before cloning the
  settings snapshot. Unbound keys leave the hook without two atomic refcount
  operations and without entering the macro router.

## Website and releases

- `https://fuvji.github.io/droplet/` is the only product URL. The old
  Freebuff deployment was unpublished; its URL no longer serves the site.
- A downloads section detects the visitor's OS locally, highlights the
  Windows build, and keeps Linux/macOS honest instead of linking to files
  that do not exist.
- The preview frames gained a restrained 3D tilt, smoother easing, and a
  reduced-motion fallback.
- The module grid uses the same transparent, original glyph language as the
  app.
- The founder credit is `@epufk`.
- A tag workflow builds and publishes the Windows portable ZIP and checksums
  on GitHub Releases.

## Known limits

- No live Minecraft client is available in this workspace, so hit
  registration and the new same-frame input ordering are unverified in game.
- Windows is the only supported platform. Linux `.deb`/AppImage/`.tar.gz` and
  macOS `.dmg`/`.zip`/`.img` packages are not produced because the core has
  not been ported.
- The portable exe is unsigned. The MSIX uses a development certificate.
- No auto-updater. Silent self-updating would require network access and a
  signed update channel, contradicting the current no-network design.
