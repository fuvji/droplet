# Droplet 2.10.1 — accurate game detection

Released 2026-11-11.

Droplet 2.10.1 fixes the false “Game detected” state. The previous watcher
accepted any visible window with “Minecraft” in its title, so browsers,
Discord, editors, and the launcher could light the badge. Detection now
requires the owning process to be a real Minecraft process.

## Detection

- Window title and class are only candidate hints. The owning process image is
  resolved with `QueryFullProcessImageNameW`.
- Java clients must run under `javaw.exe` or `java.exe` with a GLFW/LWJGL class
  or a recognized client title. Bedrock must own `Minecraft.Windows.exe`.
- Browsers, Discord, editors, and `MinecraftLauncher.exe` are rejected.
- Two consecutive samples (about 320 ms) are required before “Game detected”;
  a miss clears immediately. Cold discovery scans every 8 ticks (1.28 s)
  instead of every 12.
- A cheap class/title prefilter avoids opening unrelated processes. The
  `Only in Minecraft` gate and the badge use the same process-verified state.
