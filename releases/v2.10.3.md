# Droplet 2.10.3 — click-through corners, lighter watcher

Released 2026-11-11.

Droplet 2.10.3 is a narrow interaction and background-work polish release. The
rounded panel still looks and captures the same; the transparent corner pixels
and the presence watcher now behave correctly.

## Click-through corners

- Windows 11's DWM clip keeps the antialiased 8 px corner. On that path, the
  transparent quarter-rounds now return `HTTRANSPARENT` instead of `HTCLIENT`,
  so a click in the invisible corner goes to what is underneath.
- The center and straight edges remain clickable. The hit test uses the same
  **8 px** logical radius as the visual clip and scales with the window DPI.
- The Windows 10 GDI rounded-region fallback is unchanged. That region already
  excludes its clipped corners from hit testing.
- A live `WM_NCHITTEST` check on the running window returned **-1** at both
  rounded corners and **1** at the center and top edge.
- A pure unit test now covers the hit geometry. Tests: **25 / 25**.

## Presence watcher

- After a foreground game window is verified, its HWND is cached. While that
  same window remains foreground, the 160 ms watcher no longer resolves the
  process image again.
- A foreground change still revalidates; a closed game window still clears the
  badge; the two-sample confirmation and 8-tick cold discovery are unchanged.
- This removes redundant process queries. No input-latency, game-tick, or
  frame-time speedup is claimed.
