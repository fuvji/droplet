# Droplet 2.10.14

Released 2026-11-16. This fixes the square corner that remained after 2.10.13.

## What was still wrong

The GDI window region was genuinely rounded and DWM's border line had been
removed, but the region path also set `DWMWA_WINDOW_CORNER_PREFERENCE` to
`DWMWCP_DONOTROUND`. DWM therefore drew its compositor drop shadow around the
full square window rectangle. Against a lighter desktop that shadow read as a
pale square corner outside the radius: the window was clipped, but its shadow
was not.

## Fix

- The region path now asks DWM for `DWMWCP_ROUND` instead of `DONOTROUND`. DWM's
  shadow follows the same 8 px silhouette as the GDI region; the square corner
  wedge is gone.
- `DWMWA_BORDER_COLOR` remains `DWMWA_COLOR_NONE`, so DWM does not paint a
  competing border. Non-client rendering remains enabled: disabling it was
  tested and reverted because it also disabled acrylic and let desktop text show
  through the panel.
- The GDI region remains authoritative and is still replaced on DPI changes.
  Windows 10, where the corner-preference attribute is unsupported, keeps the
  region clip.
- All four 624×408 captures were regenerated with `PrintWindow` and the live
  `GetWindowRgn` alpha mask. They show the actual live silhouette, not a
  hardcoded rounded mask.

## Verification

- A live-window capture with a magenta backdrop has magenta at the exact
  top-left corner and no square shadow wedge. `GetWindowRgn` still reports a
  rounded region.
- The window remains 624×408; the region type is 3 at this DPI.
- `cargo test --release --locked --target x86_64-pc-windows-gnu`: 39 passed.
- `tools/check-release.ps1`: 67 checks passed.
- `powercfg /requests` requires administrator elevation and was not run, so the
  anti-sleep request is implemented and compiled but not independently
  observed here.
- No separate Windows 10 machine or live Minecraft client was available. Live
  injection, hit registration, and per-device timer floors remain unverified.

## Boundaries

Droplet remains local and visible. It has no game-memory access, network calls,
telemetry, streamproof/capture-evasion mode, anti-cheat bypass, input disguise,
or silent auto-updater. The portable exe is unsigned, so SmartScreen may warn.
