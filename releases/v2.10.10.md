# Droplet 2.10.10

Released 2026-11-14. This is a correctness and input-edge release for the
Crystal return path, DPI transitions, and trigger bindings. It does not claim a
CPU, latency, or render-speed improvement.

## Highlights

- **Busy Crystal actions no longer consume a toggle-off Return request.** The
  restore path acquires the same `CRYSTAL_BUSY` gate as Crystal before taking
  the generation request. If the gate is held, the request remains pending and
  the worker retries after the gate is released.
- **A fresh Crystal cycle cancels a stale delayed restore.** A quick off/on
  cannot leave an old worker waiting to put the Return slot back in the middle
  of the next Obsidian/Crystal sequence.
- **DPI changes end every pointer drag.** `WM_DPICHANGED` clears the UI slider
  drag along with window drag state. Lost capture and missed button-up paths
  also drop the pointer gesture, so a slider cannot follow the mouse with a
  button up.
- **Trigger assignments take ownership.** Assigning an input already owned by
  another trigger clears the old owner. Legacy duplicate configs use the later
  module, which makes Anchor usable on `XButton1` despite Breach's default.
- **Every captured key can be rebound.** Keys without a friendly label are
  stored as `vkXX` and parsed back instead of being accepted by capture but
  ignored by the route.
- **Release consistency checker.** `tools/check-release.ps1` validates the
  version, executable size and SHA-256, release test count, 624×408 capture
  dimensions, release workflow hash, and local site links.

## Boundaries

Droplet remains local and visible. It has no game-memory access, network calls,
telemetry, streamproof/capture-evasion mode, anti-cheat bypass, input disguise,
or silent auto-updater. The portable exe is unsigned, so SmartScreen may warn.
Live Minecraft injection and hit registration remain unverified here.
