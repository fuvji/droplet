# Droplet 2.10.7

**Windows x64 portable · 2026-11-12**

## Event-gated armed reads

The armed game path no longer copies settings when nothing needs them.

- **Sprint:** the watcher checks the pulse deadline before cloning settings.
  While W is held, settings reads fall from one every 8 ms (125/s) to at most
  one per 100 ms (10/s). The 8 ms watcher poll and 100 ms pulse schedule are
  unchanged.
- **Crosshair:** the watcher samples the cursor first and reads settings only
  on a magenta flash, instead of every 16 ms while focused. The 16 ms sampling
  cadence is unchanged.
- **Unchanged:** bindings, focus gating, sprint reset behavior, 8 px corners,
  game detection, presence, and the visible-composition model.
- **Not claimed:** no measured CPU reduction, end-to-end latency speedup,
  zero-latency behavior, or render-speed improvement. The game tick and Windows
  scheduling remain the boundary.
