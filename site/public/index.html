01 / Interface

The actual panel.

Captured from the shipped Windows build, not a mockup. 648 × 432, keyboard-first, and composed entirely with the native Windows drawing stack.

02 / Anchor

The Anchor,
made deliberate.

A charged anchor detonates when it is used without glowstone. Hydrogen runs the whole exchange as one settled sequence, then gets out of the way.

01

Place

Select the anchor slot and use it. A full tick lets the client register the placement.

02

Charge

Select glowstone and use once. Extra charges add delay without improving reach.

03

Clear

Switch away from glowstone. That switch is the detonation input, not another use.

04

Detonate

Right-click with the totem equipped. The busy guard holds through the blast tick.

SEQUENCE GUARDRAILS

Nothing clever in the dark.

  • All three slots must be valid and distinct.
  • Every step keeps the 50 ms game-tick floor.
  • A busy guard prevents overlapping swaps.
  • Invalid slots fail closed; nothing is injected.
  • The master switch and focus gate still apply.
One press → one complete sequence

05 / Distribution

Closed,
plainly stated.

Hydrogen is a proprietary Windows application. This page is product documentation, not an open-source repository. Source code, build scripts, and internal engineering notes are not distributed.

  • The shipped binary is the product. There is no public source download.
  • The panel is visible to screen capture and streaming tools; it does not hide from them.
  • No telemetry, analytics, network calls, or game-memory access.
