Performance

One read.
Not twenty-four.

The hook used to ask the same question for every event: does this binding match? 2.5.0 builds the answer once, when settings change, and keeps the event path to a single indexed lookup.

The index is built once.
The hook stays thin.

Bindings are parsed when settings publish, not when a key goes down. The resulting table is read by the low-level hook without scanning strings, and it is rebuilt whenever a binding changes.

0allocations added to the event route

50 msthe real tick boundary
Hard boundary

There is no zero-latency mode. Minecraft observes input on its 50 ms tick, and Windows, the device, and the client add their own scheduling. Hydrogen reduces its own routing work; it does not remove the game loop.

Questions

No magic.
Just limits.

The useful version of a product page says what it cannot do, too.

Is Hydrogen zero latency?

No. Hydrogen has a faster routing decision in 2.5.0, but Minecraft still observes input on a 50 ms tick and Windows adds scheduling. The measured number is a routing-table microbenchmark, not a promise about game response.

Does it bypass anti-cheat or hide from scans?

No. Hydrogen does not read or modify game memory, hide processes, evade scans, or disguise input. It sends ordinary keyboard and mouse events through SendInput and remains visible to capture.

Why is there no gameplay video?

No live Minecraft client is available in this workspace, so there is no honest gameplay footage to publish. The site shows the native panel capture and a CSS motion study instead. A real clip can be added after live validation.

How are the benchmark numbers measured?

The release test warms both paths, then times 1,000,000 lookups of the same key event on an AMD Ryzen 7 5700G. The indexed path reads one array; the old path scans the bindings. The test and method are in BENCHMARKS.md.

Does the site run ads?

No third-party ad client, analytics, or cookies. Sponsor placements are direct and static; sponsor links leave the site. See the sponsor inventory.
