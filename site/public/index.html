02Timing

The clock
is the feature.

Every sequence is bounded by the game tick and by the range you choose. Nothing here claims zero latency; the useful number is the one the client can actually observe.

Sprint1.000 Hz

Immediate pulse on W, then one pulse every second. Physical W only; injected events never keep it running.

02505007501000 ms
W-Tap132–148 ms

S-Tap by default. A full tick separates the release and the forward re-press, and repeat key-down events are suppressed through the tap window.

050100150200 ms
Anchor50 ms / step

Place, charge, clear, detonate. Every step keeps the 50 ms tick floor, and a busy guard prevents overlapping swaps.

03Local brain

Adaptive on warm-up.
Bounded at output.

The AI brain is a deterministic cadence estimator, not a model download. It learns how quickly you are re-triggering a module, then picks a wait inside your Min/Max.

  1. 01
    Warm-upEarly samples move the estimate quickly.
  2. 02
    SettledThe step size bottoms out at 12.5%.
  3. 03
    ClampedYour configured range always wins.

07Distribution

Public source,
proprietary product.

Hydrogen is a proprietary Windows application. The source is public at GitHub for inspection, but public availability is not an open-source licence and grants no right to redistribute the product.

  • The source repository is public. The shipped binary remains the supported product.
  • The panel is ordinary visible desktop composition. It does not hide from capture tools.
  • No telemetry, analytics, network calls, or game-memory access.
