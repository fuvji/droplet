2.10.17.

2.10.17 is the translucent-glass release. The layered panel composites at 84% opacity, so the desktop reads through a smooth gray aurora with low-alpha slate, indigo, and mauve blooms, and the rail becomes a second pane of glass. The LOCAL / WINDOWS eyebrow is gone; every label is Segoe UI Light with no bold weight, and the window radius grew from 12 to 18 px with 15 px cards. A first GDI+ bloom path measured 81.45 ms and was replaced by a cached pixel backdrop that measures 5.32 ms for a full repaint. The 0.5 ms timer, anti-sleep state, event-driven paint, and Windows 10-safe alpha silhouette are retained. The tagged source still builds the published exe with pinned GNU toolchain, tests first, a normalized artifact, verified SHA-256, provenance, and the local harness. The harness cannot record synthetic Shield output here; that check is unresolved, not passed.

2.10.17 notes

Translucent,
quieter glass.

A readable ledger. Every item is implemented in the source or measured on the release build; the unverified items are labelled.

Three DPI scales, one silhouette

  • tools/capture-tabs.ps1 sends WM_DPICHANGED and captures the live Core panel at 100%, 125%, and 150%. The physical captures are 624×408, 780×510, and 936×612.
  • tools/check-dpi-corners.ps1 reads each PNG and requires all four outer corner alphas to be zero, the corner boxes to mirror horizontally and vertically, and the straight edge rows and columns to remain opaque.
  • The Rust mask test calls the same alpha function at 1.0, 1.25, and 1.5 scale, so a right/bottom arc centre on the window edge or a square corner fails before packaging.
  • The published DPI images are linked from the artifact table above. A separate live desktop capture over a magenta backdrop showed the backdrop through all four corners at all three scales; that was a verification aid, not a shipped mode.
  • The captures exercise the application's DPI path on a 96 DPI host. They are not a physical 125% or 150% monitor test; that hardware was not available.

Thin type on translucent glass

  • The near-black frame is gone. A graphite wash plus three very low-alpha aurora blooms sits behind the cards, and the whole layered surface composites at 84% opacity, so the desktop shows through.
  • The LOCAL / WINDOWS eyebrow is removed. One 16 px light title sits in the header; every label is regular-weight Segoe UI Light (Segoe UI fallback), with dim tones lifted for thin stems.
  • The window radius is 18 px and card corners are 15 px, so the silhouette and tiles read as clean curves instead of thick tonal wedges. Sliders and separators are thinner, and icon strokes scale with DPI.
  • DWM system-backdrop and accent requests were removed: on this layered window they painted an opaque layer behind the surface and cancelled the translucency. A live capture over a bright test backdrop confirmed the desktop show-through.
  • No new dependency, texture, external font, network path, or copied asset was added. The 624×408 logical layout is unchanged.

Alpha and timing kept

  • All four 18 px arcs use mirrored 4×4 coverage sampling. Paint, the layered alpha mask, hit testing, DPI resizing, and the capture helper share the radius.
  • The alpha and premultiply work remains one full-buffer pass. The aurora backdrop is cached per surface size and copied into the buffer; the first GDI+ bloom version measured 81.45 ms and is gone. No end-to-end speedup is claimed.
  • Keep panel open remains on by default and Reset restores it. The 2.10.12 held 0.5 ms timer, anti-sleep state, and DPI-correct hit testing are retained.
  • The transparent quarter-rounds remain click-through, and the Windows 10-safe silhouette does not rely on DWM's Windows 11-only corner preference.

Source-built provenance

  • The tag workflow installs Rust 1.99.1 and the GNU target, checks formatting, runs the release tests, builds the exe, verifies its normalized SHA-256, and attests the exe and checksum with GitHub build provenance.
  • tools/build-release.ps1 remaps workspace and target paths; tools/normalize-pe.ps1 zeroes the PE timestamp. Two clean targets produce the same 561,152-byte artifact.
  • The workflow publishes only the source-built exe, checksum, and droplet.intoto.jsonl; the checked-in exe is a comparison target, not the uploaded file.
  • Tests are 42 / 42. SHA-256 601c1e60957f149949f61de0ddfb44d0513e1141b2c31e0e2a8ccd0460378027. No CPU, latency, or speedup claim.

Input harness and limits

  • tools/input-harness.ps1 records Droplet's injected output with low-level hooks against a temporary profile. The focus-only and master-off cases pass; the Shield case records no events here.
  • A standalone low-level hook also received no synthetic q, so the missing output is upstream of Shield. The Shield result remains unresolved; it is not claimed as a pass.
  • No live Minecraft client was available, so in-game hit registration is not verified. No latency or end-to-end speedup is claimed.

Not added

  • No streamproof or capture-evasion mode, anti-cheat bypass, process hiding, log erasure, or input disguise.
  • No game-memory reading, network calls, telemetry, installer, MSIX/AppX, or ZIP.
  • No Linux or macOS package until the Win32/GDI+ platform layer is ported.
  • No zero-latency claim and no silent auto-updater.

Ledger

Release
history.

The versioned notes in the repository are the source of truth. This page is a readable mirror, not an automatically generated feed.

2.10.17

Translucent aurora glass, thin type

The layered panel composites at 84% opacity, so the desktop reads through a gray graphite wash with low-alpha slate, indigo, and mauve blooms; the rail is a second pane of glass. The LOCAL / WINDOWS eyebrow and every bold weight are gone, and all text is Segoe UI Light. The window radius grows to 18 px, cards to 15 px, sliders and separators thin out, and icon strokes scale with DPI. DWM backdrop requests were removed because they made the layered window opaque. The cached pixel backdrop replaced a measured 81.45 ms GDI+ bloom path and measures 5.32 ms for a full repaint. Tests: 42 / 42; exe: 561,152 bytes.

2.10.16

DPI corner regression, cleaner glass

Live 100/125/150 DPI captures and a PNG checker require transparent, mirrored corners and opaque straight edges; a Rust unit test covers all three scales. The GUI gains a graphite wash, filled rail selection, stronger titles, white switch knobs, and slider halos using the supplied Apple references as design language. The 12 px layered silhouette, 0.5 ms timer, anti-sleep state, and one-pass alpha composition are retained. A measured card-shadow path was removed. Tests: 42 / 42; exe: 558,080 bytes.

2.10.15

Corner spikes fixed

The interim layered path centred the right and bottom arcs on the window edge, leaving a one-pixel spike at those corners. All four 12 px arcs now use mirrored 4×4 coverage sampling; paint, hit testing, DPI sizing, and captures share the same radius. Alpha, premultiply, and corner rewriting run in one buffer pass, and Reset restores Keep panel open to on. The silhouette does not depend on DWM's Windows 11-only corner preference, so Windows 10 uses the same path. A local dwm.log records the DWM HRESULTs, region clear, size, and DPI. The input harness could not record synthetic Shield output here; that result is unresolved. Tests: 41 / 41; exe: 556,032 bytes.

2.10.14

DWM shadow followed the radius

The region path asked DWM for DWMWCP_ROUND instead of DONOTROUND, so the compositor shadow followed the 8 px silhouette and the square wedge outside the corners was removed. Border color stayed clear and non-client rendering stayed enabled for acrylic. Captures used the live window region. Tests: 39 / 39; exe: 550,400 bytes.

2.10.13

DWM square frame removed

The authoritative GDI region is unchanged, but the region path now clears the border color and tells DWM not to round; non-client rendering stays enabled for acrylic. The light square outside the corners is gone. Captures use GetWindowRgn for alpha instead of a hardcoded mask. The 2.10.12 timer, anti-sleep, DPI, and provenance work is retained. Tests: 39 / 39; exe: 550,400 bytes.

2.10.12

Windows 10 corners, held 0.5 ms timer

The GDI 8 px region is now the primary clip on Windows 10 and 11, and DWM is only a fallback. Low latency requests the kernel's finest timer value, reasserts 0.5 ms once per second while enabled, and holds a system-required execution state. Tagged-source build, provenance attestation, and the local input harness remain. Tests: 39 / 39; exe: 550,400 bytes.

2.10.11

Final handoff, deterministic captures

rustfmt-clean source, load-time cleanup of legacy duplicate bindings, and four captures generated from an isolated deterministic profile. Anchor is shown on XButton1. Tests: 38 / 38; exe: 547,840 bytes.

2.10.10

Busy-safe Crystal, trigger ownership

A busy Crystal action cannot consume a toggle-off Return request; DPI changes clear the slider drag; trigger rebinding takes ownership, and legacy duplicates resolve to the later module. Captured vkXX keys round-trip. Tests: 37 / 37; exe: 547,328 bytes.

2.10.9

Auto Crystal Return, DPI hit testing

Hold the Crystal trigger for 160 ms or switch its toggle off to restore a configurable Return slot; a short tap leaves the hotbar alone. Scaled pointer hit testing now uses physical coordinates at 125% and 150%. Tests: 31 / 31; exe: 545,280 bytes.

2.10.8

Smaller portable exe

Hidden ShellExecuteW replaces the only std::process::Command use, and rust-lld + ICF cuts the binary to 542,720 bytes. Event-gated reads are unchanged.

2.10.7

Event-gated reads

Sprint settings are read only when a pulse is due, and crosshair settings only on a magenta hit; polling and bindings are unchanged.

2.10.6

Idle sprint poll

The sprint watcher parks at 100 ms while inactive and wakes immediately on focus or settings changes; the armed 8 ms cadence is unchanged.

2.10.5

Idle watcher gates

The sprint and crosshair watchers skip the settings lock while inactive; cadence and visuals are unchanged.

2.10.4

Transparent mark, leaner loop

The favicon tile and brand plate are gone, and the focus-only presence loop no longer takes the settings lock every 160 ms.

2.10.3

Click-through corners, lighter watcher

Transparent rounded corners pass clicks through, and the watcher reuses a verified foreground game window instead of re-resolving it every 160 ms.

2.10.2

Clean corners, matched mark

DWM-first antialiased 8 px corners with a hard-region fallback, and a favicon/header mark that matches the app's outlined droplet.

2.10.1

Process-verified game detection

Browsers, Discord, editors, and the launcher no longer trigger Game detected; two samples confirm a real Java or Bedrock process.

2.10.0

Hydrogen Anchor, tighter corner

Literal A6 Anchor order, 47/53 ms defaults with Air loop, one 8 px radius across paint and capture, and a local vault-graph site.

2.9.3

Reliable Anchor, exe only

Anchor 55/65 ms safe settle, top accent strip and outer rim removed, and MSIX/AppX/ZIP packaging retired for one direct 591,872-byte exe.

2.9.2

Independent sliders, knob switches

Min/Max no longer rewrite each other, the 28×16 knob switch returns, Anchor 37–97 / 43–103 with 37/43 defaults, outer rim removed, Self-destruct restored. Last release with ZIP/MSIX artifacts.

2.9.1

Borderless cards, text controls

Module glyphs removed, text ON/OFF pills, borderless cards, Anchor tick-floor row retired, 592,384-byte exe and 301,774-byte MSIX.

2.9.0

Power controls and downloads

Round power buttons, transparent item glyphs, compact Dash, sticky hide, 1 s self-destruct, same-frame Dash/Shield/Pearl input, Windows ZIP and MSIX, GitHub release workflow.

2.8.0

Fitted corners and lighter paint

One 13 px radius across paint, window region, and capture mask; allocation-free binding chips; 594,944-byte binary; editorial site rebuild.

2.7.0

Accent and per-module modes

RGB presets and channel sliders, Hold/Toggle chips on every trigger card, and tighter fast-module defaults.

2.6.2

Rounded window, single mark

Window corners follow the painted radius; the brand mark becomes one transparent droplet.
