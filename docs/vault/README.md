# Droplet vault

A portable Obsidian-compatible note graph. Copy this folder into any vault, or
open it directly as a vault. The notes use wikilinks so the graph view shows the
product, performance, release, and website work as one connected system.

Start at [[droplet]], then follow [[performance]], [[release]], and [[website]].
[[AGENTS]] contains the universal working rules for any project that imports
this vault.

The actual Obsidian vault path on the user's machine is not recorded in this
repository. This kit is the versioned source; do not assume a private vault
location exists.
